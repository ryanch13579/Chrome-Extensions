# Chrome Extensions

This repository contains the source code for various Chrome extensions designed to improve the YouTube browsing experience.

1. [**YouTube Anti-AI Slop**](https://chromewebstore.google.com/detail/anti-youtube-ai-slop/oafnefikfbmilkcgnbljaoebiaaejeke) – Automatically identifies AI-generated content on YouTube and either highlights or hide flagged videos.
2. [**YouTube Anti-Paywall**](https://chromewebstore.google.com/detail/hide-paid-youtube-videos/kbddlgpdbbfccdahodnengjhfaaekopb) – Hides YouTube content that requires payment to access.
3. **YouTube Pomodoro Timer** – Chrome extension that loops any YouTube video as background music alongside a Pomodoro timer, with automatic music pausing on breaks, chimes and notifications.
